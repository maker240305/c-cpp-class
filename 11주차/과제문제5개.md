# 11주차 과제 - 5문제

## 1번. 다음 선언 이후에 실행할 수 있는 문장으로 **옳은 것**은? (각 보기는 독립적으로 판단한다.)

```c
char *string = "Hello";
char array[] = "Array";
```

1. `string = "World";`
2. `array = "World";`
3. `array++;`
4. `array = string;`

## 2번. 다음 코드의 **출력 결과**는?

```c
#include <stdio.h>

int main(void)
{
    char array[] = "Array";
    array[2] = '\0';

    printf("%s\n", array);
    return 0;
}
```

1. `Array`
2. `Ar`
3. `Arr`
4. `ay`

## 3번. 다음 C언어 코드의 실행 결과로 **올바른 것**은?

```c
#include <stdio.h>

struct Student {
    int score;
};

int main(void) {
    struct Student s[3] = {{70}, {80}, {90}};
    printf("%d", s[1].score + s[2].score);
    return 0;
}
```

1. `150`
2. `160`
3. `170`
4. `180`

## 4번. 다음 C언어 코드의 실행 결과로 **올바른 것**은?

```c
#include <stdio.h>

struct Point {
    int x;
    int y;
};

void change(struct Point *p) {
    p->x += 5;
    p->y = p->x + 2;
}

int main(void) {
    struct Point a = {10, 20};
    change(&a);
    printf("%d %d", a.x, a.y);
    return 0;
}
```

1. `10 20`
2. `15 20`
3. `15 17`
4. `10 12`

## 5번. 다음 C언어 코드의 실행 결과로 **올바른 것**은?

```c
#include <stdio.h>

enum State {
    READY = 2,
    RUNNING,
    STOP = 7,
    PAUSED
};

int main(void) {
    printf("%d %d", RUNNING, PAUSED);
    return 0;
}
```

1. `2 7`
2. `3 8`
3. `3 7`
4. `1 3`

---


| 문제 | 정답 | 해설 |
| --- | --- | --- |
| 1번 | 1 | 포인터 변수 `string`에는 다른 문자열 리터럴의 주소를 대입할 수 있다. 배열 이름에는 대입 연산이나 증가 연산을 적용할 수 없다. |
| 2번 | 2 | `%s`는 첫 널 문자를 만날 때까지 출력한다. 인덱스 2에 널 문자를 넣었으므로 인덱스 0과 1의 문자인 `Ar`만 출력된다. |
| 3번 | 3 | 구조체 배열의 인덱스는 0부터 시작한다. 따라서 `s[1].score`는 80이고 `s[2].score`는 90이므로 두 값을 더한 170이 출력된다. |
| 4번 | 3 | `change(&a)`는 구조체 변수 `a`의 주소를 함수에 전달한다. `p->x += 5`에 의해 x는 15가 되고, `p->y = p->x + 2`에 의해 y는 17이 된다. 구조체 포인터를 사용했으므로 원본 구조체의 값이 변경된다. |
| 5번 | 2 | 열거형에서 값을 지정하지 않은 멤버는 바로 앞 멤버의 값보다 1 큰 값을 갖는다. 따라서 `RUNNING`은 3이고 `PAUSED`는 8이므로 `3 8`이 출력된다. |
