버블 정렬 — 학생 성적 문제에도 그대로 사용

void bubble(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                int temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;
            }
        }
    }
}
왜 n - 1 - i인가?
a[j+1]까지 비교하므로 끝에서 한 칸을 빼고, 이미 뒤에 확정된 i개도 제외한다. 내림차순은 비교를 <로 바꾼다.

선택 정렬 — 비교 중에는 위치만 기억

void selection(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIndex = i;
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[minIndex]) minIndex = j;
        }
        int temp = a[i];
        a[i] = a[minIndex];
        a[minIndex] = temp;
    }
}

삽입 정렬 — key를 보존하고 오른쪽으로 이동

void insertion(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;
    }
}
빈칸 채점 포인트
① i는 1부터 ② key는 a[i] ③ j는 i-1 ④ 이동은 a[j+1]=a[j] ⑤ 삽입은 a[j+1]=key. j >= 0을 먼저 검사하면 음수 인덱스 접근을 막는다.

포인터가 실제로 이동하는 예제

int a[] = {10, 20, 30};

주소 연산의 단위
p++는 가리키는 자료형 하나만큼 이동한다. int가 4바이트인 환경이면 int*의 이동 폭은 4바이트다. sizeof(p)는 포인터 자체 크기, sizeof(*p)는 가리키는 자료형 크기다. 둘은 다른 질문이다.

역순 순회 — 주관식에서 바로 쓸 패턴

void printReverse(int *a, int n) {
    int *p = a + n;      // 배열 끝 바로 다음
    while (p > a) {
        --p;             // 실제 원소로 먼저 이동
        printf("%d ", *p);
    }
}
범위의 끝
a+n은 만들고 비교할 수 있지만 역참조하면 안 된다. 마지막 원소를 읽은 뒤 a-1을 만드는 방식도 피한다. 위 코드는 p==a일 때 멈춘다.

배열과 함수: 원본이 바뀌는 이유

5주차/arr.c · 7주차/studentSort.c · 4주차 PDF 9장

C의 인자 전달은 값 전달이다. 정수 값을 복사하는지, 원본을 가리키는 포인터 값을 복사하는지가 다르다.

void one(int x) { x *= 2; }
void all(int a[]) {
    for (int i = 0; i < 3; i++) a[i] *= 2;
}
// main 안에서 실행
int a[] = {10, 20, 30};
one(a[0]);  // a는 10 20 30
all(a);     // a는 20 40 60
호출복사해 전달하는 것함수 내부 변경의 영향
one(a[0])정수 10매개변수 x만 바뀜
all(a)첫 원소를 가리키는 포인터 값그 주소를 통해 원본 원소를 바꿈
swap(&x, &y)x와 y를 가리키는 포인터 값*p, *q로 원본 x, y를 바꿈

배열의 원소 수와 초기화

int a[5] = {7, 4};           // 7 4 0 0 0
int n = sizeof(a) / sizeof(a[0]); // 이 위치에서 5
int b[] = {7, 4, 5, 1, 3};   // 초기값으로 크기 결정
sizeof 함정
함수 매개변수의 int a[]는 int *a로 조정된다. 그 함수 안의 sizeof(a)는 배열 전체 크기가 아니다. 배열을 처리하는 함수에는 원소 수 n도 함께 전달한다. 배열 자체와 포인터 변수는 서로 다른 자료형이다.

원본 두 값을 바꾸는 함수

void swap(int *p, int *q) {
    int temp = *p;
    *p = *q;
    *q = temp;
}
// 호출: swap(&x, &y);

학생 성적 문제에서 반복되는 세 문장

int score[50];
int *p = score;
scanf("%d", p + i);       // 입력 대상의 주소
printf("%d ", *(p + i));  // 출력할 값
// n개를 오름차순 정렬한 뒤 (n >= 1)
printf("최고: %d\n", *(p + n - 1));
printf("최저: %d\n", *p);
입력과 출력
scanf의 p+i는 이미 주소다. printf로 원소 값을 출력할 때는 *(p+i)로 읽는다. 학생 수는 n<1 || n>50이면 거절해야 최고·최저점 접근도 유효하다.

각 숫자가 몇 번 나왔는지 세기

void countDigits(int n, int cnt[]) {
    // n은 음수가 아닌 정수, cnt[10]은 0으로 초기화
    do {
        cnt[n % 10]++;
        n /= 10;
    } while (n > 0);
}
// n=1002 → cnt[0]=2, cnt[1]=1, cnt[2]=1
0 입력도 한 자리다
처음부터 while(n>0)이면 n=0을 한 번도 세지 못한다. 위 do~while은 0을 한 번 센다. 기존 num.c는 곱이 양수인 입력에서 자리수 집계 패턴을 확인하는 예제다.

점수 구간 집계

int cnt[11] = {0}, score;
while (1) {
    scanf("%d", &score);    // 입력은 0~100이라고 가정
    if (score == 0) break;  // 이 문제에서만 0은 종료 신호
    cnt[score / 10]++;
}
for (int i = 10; i >= 0; i--)
    if (cnt[i] > 0)
        printf("%d : %d\n", i * 10, cnt[i]);

재귀: 호출 순서와 출력 순서

4주차/jegi.c · 4주차 PDF 재귀 함수

종료 조건을 확인한 뒤, 재귀 호출 앞에서 출력하는지 뒤에서 출력하는지를 본다.

void printNum(int n) {
    if (n == 0) return;
    printNum(n - 1);
    printf("%d ", n);
}
// printNum(3) → 1 2 3
printNum(3)의 흐름실제로 일어나는 일
3 → 2 → 1 → 0아직 printf까지 도달하지 못한 호출들이 쌓임
n=0return으로 끝남
n=1로 복귀1 출력
n=2로 복귀2 출력
n=3으로 복귀3 출력
void printDown(int n) {
    if (n == 0) return;
    printf("%d ", n);
    printDown(n - 1);
}
// printDown(3) → 3 2 1
주관식 설명 문장
재귀 호출 뒤에 출력하면 더 작은 n의 호출이 끝난 뒤 현재 n을 출력한다. 앞에서 출력하면 현재 n을 먼저 출력하고 다음 호출로 들어간다. 두 예제의 입력은 n≥0이다.
교재의 팩토리얼·피보나치도 종료 조건부터
int factorial(int n) {         // n >= 0, 결과가 int 범위 이내
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
int fibonacci(int n) {         // n >= 0, 결과가 int 범위 이내
    if (n <= 1) return n;
    return fibonacci(n - 1) + fibonacci(n - 2);
}
// factorial(4)=24, fibonacci(5)=5

종료 조건, 더 작은 문제로 바뀌는 인자, 반환값 결합을 각각 확인한다. 조건을 없애면 정상적으로 재귀를 종료할 수 없다.

switch: 들어간 case부터 순서대로 실행

switch (score / 10) {
    case 10:
    case 9: grade = 'A'; break;
    case 8: grade = 'B'; break;
    case 7: grade = 'C'; break;
    case 6: grade = 'D'; break;  // 실습에는 이 break가 빠짐

가변 인자 — 네 가지 이름을 정확하게

#include <stdarg.h>
int sum(int n, ...) {
    va_list args;
    int total = 0;
    va_start(args, n);
    for (int i = 0; i < n; i++)
        total += va_arg(args, int);
    va_end(args);
    return total;
}
// sum(3, 2, 5, 9) → 16
이름역할
va_list가변 인자 목록을 다룰 변수의 자료형
va_start가변 인자 처리를 시작
va_arg지정한 자료형의 다음 인자를 읽음
va_end가변 인자 처리를 종료
첫 번째 인자는 개수
이 sum 함수에서 n은 뒤에서 읽을 int 인자의 개수다. 개수·자료형을 함수가 자동으로 알아내는 것이 아니다. 읽을 개수와 실제 인자가 맞아야 한다.

시험 10분 전: 말로 답해보기

정답을 먼저 보지 않고 한 문장으로 설명해보기

01 버블·선택·삽입의 첫 패스가 다른 이유를 말할 수 있는가?

버블은 최댓값을 오른쪽, 선택은 최솟값을 왼쪽에 확정한다. 삽입은 다음 key를 앞의 정렬 구간에 넣는다.

02 삽입 정렬의 마지막 대입은 a[j]인가 a[j+1]인가?

a[j+1]=key. 반복이 끝난 j는 삽입 위치의 한 칸 앞이다.

03 (*p)++와 *p++는 각각 무엇을 바꾸는가?

전자는 원소 값, 후자는 포인터 위치를 바꾼다. *p++는 *(p++)로 묶인다.

04 배열을 함수에 넘기면 왜 원본이 바뀔 수 있는가?

첫 원소를 가리키는 포인터 값이 복사되어 그 주소로 원본에 접근하기 때문이다. C의 값 전달 원칙은 그대로다.

05 scanf에 p+i를 주는가 *(p+i)를 주는가?

p+i. scanf에는 입력을 저장할 주소가 필요하다.

06 100점을 score/10으로 집계하려면 몇 칸인가?

11칸. 인덱스 10이 필요하다.

07 402의 자리를 뒤에서 떼면 0은 사라지는가?

2, 0, 4 순서로 나온다. 중간의 0도 한 자리로 처리한다.

08 재귀 호출 뒤 printf가 있으면 언제 출력하는가?

더 깊은 호출이 반환된 뒤 현재 호출에서 출력한다. printNum(3)은 1 2 3.

09 static 지역변수는 함수가 끝나면 값이 사라지는가?

범위는 지역이지만 수명은 프로그램 전체라 다음 호출까지 값을 유지한다.

10 (double)(7/2)와 (double)7/2는 같은가?

각각 3.0과 3.5. 정수 나눗셈 전에 변환했는지 구분한다.

11 switch에서 break가 빠지면 다음 case도 실행하는가?

해당 case로 들어간 뒤 다음 코드로 계속 진행한다. 다음 case 조건을 새로 검사하는 방식이 아니다.

12 오름차순 정렬 뒤 최고점과 최저점은 어디인가?

n≥1일 때 최고점 *(p+n-1), 최저점 *p. 학생 수 0을 먼저 거절해야 한다.
